# Frame playground

A playground to showcase multiple components working together.

## Components

- **titleBar**: A macOS or Windows title bar with traffic lights, app name, and tabs
- **header**: Header with a select and breadcrumbs
- **navRail**: Click to switch between tabs, close tabs, and add new tabs
- **configPanel**: Control what platform and what components are showsn

## The usual

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:3000`
